## 四、额度怎么算：5 小时窗口和积分

Plus 的限额按「5 小时滚动窗口」计算，不是每天清零，本地消息和云端任务共享同一个窗口。

限额是个区间，不是死数。以 GPT-5.5 为例，Plus 档每 5 小时大约 15–80 条本地消息。浮动为什么这么大？因为每条消息烧多少额度取决于模型、任务大小和上下文长度：改两行小脚本可能只占一点点配额，让它在上万行的老项目里跑重构，十几条就可能见底。

Pro 系列的规则在 9 月底有过调整：按当时官方页面的说法，Pro 档当前没有 5 小时用量限制，但仍可能有每周限额，实际消耗受模型、任务和上下文影响。这类规则变动频繁，下单前最好去官方定价页确认当前说法。

撞了限额不用急着升档。官方给的方案是买积分（credits）续命，类似流量加油包，量级参考：GPT-5.5 平均每条消息消耗 5–45 积分。

想随时掌握余量，两个入口：CLI 里敲 `/status` 看当前会话的模型、剩余上下文和 token 用量；想看跨设备的完整用量和剩余限额，去 ChatGPT 网页端的 Codex 用量面板。养成先看再用的习惯，比突然被拦住强。
